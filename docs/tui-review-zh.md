# TUI 审核操作指南

TUI（终端交互界面）是审核和批准成绩的推荐方式。它并排显示每个学生的评分明细，并提供编辑笔记、覆盖成绩、检索过往记录等工具。

## 启动 TUI

```bash
# 只审核需复核的学生（默认）
uv run python main.py review --needs-review

# 审核全部学生
uv run python main.py review --all

# 指定某个评分 Excel 文件
uv run python main.py review --scores scores_426252.xlsx --needs-review

# 先自动通过满分，再审核其余
uv run python main.py review --auto-approve --needs-review
```

## 快捷键一览

| 快捷键 | 功能 | 是否翻页 |
|---|---|---|
| `a` | 通过并进入下一位 | 否 |
| `n` | 编辑审阅笔记——**在此写扣分理由** | 是 |
| `o` | 用系统查看器打开提交文件 | 是 |
| `r` | 打开评分标准文件 | 是 |
| `u` | 切换 Uncertain Parts 自动追加到笔记 | 是 |
| `R` | 检索——搜索已通过学生的笔记 | 是 |
| `j` | 按姓名或学号跳转到学生 | 否 |
| `s` | 跳过，下一位 | 否 |
| `b` | 返回上一位学生 | 否 |
| `q` | 退出 | — |

## 核心流程：通过笔记改分

推荐通过**审阅笔记**（`n`）调整分数。这取代了已隐藏的 `e`（编辑）和 `ov`（覆盖）命令。

### 操作步骤

1. 按 `n` 打开系统编辑器输入笔记。
2. 写下你的评语。扣分请使用以下格式：

   ```
   扣X分：原因说明
   ```

   例如：

   ```
   扣3分：7.7的等价性证明只给出了结论性语句，没有展开说明双向对应关系。
   扣2分：7.21(1)中库存边费用写成0.5，题目为0.1。
   ```

3. 保存并关闭编辑器。系统会自动：
   - 解析笔记中所有 `扣X分` 模式
   - 计算建议总分（满分 - 扣分之和）
   - 提示你确认是否覆盖成绩

4. 确认覆盖——`reviewer_override_score` 自动设置。

### 为什么用笔记代替编辑/覆盖

- **可追溯**：每次扣分的理由都记录在笔记中
- **一致性**：后续用 `R(ecall)` 检索时，扣分依据清晰可见
- **准确性**：手动编辑 `e`(dit) 需要调整原始评分明细，容易出错

## Uncertain Parts（不确定项）

如果 LLM 标记了不确定项（边界分数、字迹不清等），审核时会显示在黄色的"Uncertain Parts"面板中。

按 `u` 切换**自动追加不确定项到笔记**。开启后，第一次按 `n` 编辑时会预填充：

```
--- Uncertain Parts ---
- 字迹不清，无法判断第2题具体写了什么 (suggested: 0/10)
- borderline: 可能在7分和8分之间 (suggested: 8/10)
```

你可以决定是否在笔记中说明、调整分数，或忽略。

## 晚交检测

系统使用**北京时间（UTC+8）** 自动比对提交时间和截止时间。截止前提交的学生正确标记为按时。截止后提交的标记为晚交，扣 10 分（不超过总分）。

晚交信息会在第一次按 `n` 时预填充到笔记中（按学生跟踪，删除后不再重新出现）。

## Recall：检索过往批改记录

当需要查看之前对类似问题的给分情况时，用 `R(ecall)` 搜索已通过的笔记：

```
Action: R
Recall: search notes for: 7.4
```

输出格式：
```
2400017436_潘玥含: 题目7.4...入度...扣2分
2400017451_解成毅: 7.4...核心证明缺失...扣7分
```

这有助于保持**评分一致性**——确保不同学生的同类错误得到相近的扣分。

## Jump：快速跳转

如果 `Recall` 发现某位学生的评分可能有偏差，用 `j(ump)` 直接跳转：

```
Action: j
Jump to student (name or ID): 解成
```

TUI 会跳转到匹配的学生，你可以复查评分明细、修改笔记或通过。

## 完整审核流程

```
1. 启动 TUI：  python main.py review --needs-review
2. 对每位学生：
   a. 阅读评分明细和 LLM 推理
   b. 按需打开提交文件 (o) 和评分标准 (r)
   c. 用 扣X分 格式写笔记 (n / T)
   d. 如有自动建议覆盖成绩，确认
   e. 通过 (a) 进入下一位
   f. 如不确定，跳过 (s) 稍后处理
3. 退出时按提示保存
```
